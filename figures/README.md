# Figure source

This directory preserves the final plotting scripts and source artwork for the
five main figures. Figure 1 and Figure 2 use the public trial dataset. Figures
3–5 consume the aggregate tables in `../analysis/outputs/` plus model summaries
that are not part of this minimal package. They are included to document
layout, typography, colors, and statistical marks, not as a second copy of the
full analysis pipeline.

Rendered manuscript files and obsolete plotting versions are intentionally not
tracked.
